# Project Euler Solutions

This directory contains my solutions to problems from [Project Euler](https://projecteuler.net/), completed as part of my ongoing software engineering learning and experimentation.

## 📌 Purpose

The goals of this repository are to:

* Strengthen problem-solving and algorithmic thinking
* Explore different programming techniques and optimizations
* Track personal progress over time
* Experiment with clean code practices and documentation

## 📂 Structure

Solutions are typically organized by problem number and may include:

* Source code implementation
* Comments explaining the approach
* Notes on optimizations or alternative strategies (where relevant)

Example:

```
/001/
  solution.py
  notes.md
/002/
  solution.py
```

## ⚖️ Project Euler Policy Compliance

This repository adheres to the guidelines outlined on the Project Euler website regarding sharing solutions:

* ✅ **Problems 1–100**: Solutions may be shared publicly in this repository.
* 🔒 **Problems >100**: Solutions will **not** be posted publicly.

To remain compliant:

* All solutions for problems numbered **greater than 100** are maintained in a **private fork** of this repository.
* This ensures respect for Project Euler’s rules while still allowing me to continue tracking my progress.

## 🚀 Usage

Feel free to browse solutions for the first 100 problems if you're interested in:

* Comparing approaches
* Learning different techniques
* Reviewing implementation styles

However, if you're currently solving Project Euler problems yourself, I recommend attempting them independently first for the best learning experience.
